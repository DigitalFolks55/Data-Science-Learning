# AGENTS.md

## Project

Repository name: `Data-Science-Learning`

This project is to summarize required skills for data scientists.
Mainly create materials of jupyter notebook for providing concepts and hands-on practice.

## Working Language

* Descriptions and comments should be written in English unless requested otherwise.
* Code, module names, class names and function names should use English.

## Development Principles

1. Materials will be generated by a jupyter notebook.
2. Refer to the template for the formatting of notebook. 
 - Template locates at utils/Jupyter notebook template.ipynb
 - Ensure new notebook has same structure of template.
3. User will define suggested contents but able to add others if it is worth to be included.
4. Notebook will be stored at user-defined folder.

## Documentation Policy

Use Obsidian-compatible Markdown.
Update index files to have latest link and descriptions.
If any changes required for README.md, update it.

## Dependency Policy

Use `uv`.

Allowed commands:

```bash
uv add <package>
uv add --group dev <package>
uv remove <package>
uv sync
uv lock
uv run <command>
```

Do not edit `uv.lock` manually.

Before adding production dependencies, explain:

* Why it is needed
* Alternative options
* Runtime impact
* License, packaging, or deployment concern if relevant
