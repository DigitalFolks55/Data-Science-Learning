# References to learn Python

## 1) Official Python
- [Introducing Python, 3rd Edition](https://www.oreilly.com/library/view/introducing-python-3rd/9781098174392/)
  ISBN: 9781098174392
- [Python Command Line and Environment](https://docs.python.org/3/using/cmdline/)  
  Useful for learning how to run Python from the terminal or command prompt.
- [The Python Tutorial](https://docs.python.org/3/tutorial/index.html)  
  Official beginner tutorial for learning Python syntax and basic usage.

## 2) VS Code
- [Getting Started with Python in VS Code](https://code.visualstudio.com/docs/python/python-tutorial)  
  Beginner guide for writing, running, and debugging Python code in VS Code.
- [Running Python Code in Visual Studio Code](https://code.visualstudio.com/docs/python/run)  
  Explains how to run a Python file, run selected lines, and use the VS Code terminal.
- [Python in Visual Studio Code](https://code.visualstudio.com/docs/languages/python)  
  General VS Code Python setup guide.

## 3) Jupyter Notebook
- [Jupyter Notebook Official Website](https://jupyter.org/)  
  General information about Jupyter Notebook and JupyterLab.
- [Running Code in Jupyter Notebook](https://jupyter-notebook.readthedocs.io/en/stable/examples/Notebook/Running%20Code.html)  
  Explains how to run code cells using `Shift + Enter`.
- [Jupyter Notebook Documentation](https://jupyter-notebook.readthedocs.io/en/stable/notebook.html)  
  Useful for understanding notebooks, cells, outputs, and plots.
- [Jupyter Notebooks in VS Code](https://code.visualstudio.com/docs/datascience/jupyter-notebooks)  
  Explains how to use `.ipynb` notebooks directly inside VS Code.

## 4) Anaconda / Conda
- [Download Anaconda Distribution](https://www.anaconda.com/download)  
  Download page for Anaconda.
- [Installing Anaconda Distribution](https://www.anaconda.com/docs/getting-started/anaconda/install/overview)  
  Official Anaconda installation guide.
- [Getting Started with Conda](https://docs.conda.io/projects/conda/en/stable/user-guide/getting-started.html)  
  Official guide for basic Conda usage.
- [Managing Conda Environments](https://docs.conda.io/docs/user-guide/tasks/manage-environments.html)  
  Useful for creating, activating, and managing Conda environments.
- [Anaconda Navigator](https://www.anaconda.com/docs/tools/anaconda-navigator/main)  
  Guide for using the Anaconda GUI.
- [How to Open JupyterLab with Anaconda](https://www.anaconda.com/docs/getting-started/guides/how-to-open-jupyterlab)  
  Step-by-step guide for launching JupyterLab from Anaconda.

## 5) uv
- [uv Official Documentation](https://docs.astral.sh/uv/)  
  Main documentation for `uv`.
- [uv: Working on Projects](https://docs.astral.sh/uv/guides/projects/)  
  Useful for `uv init`, `.venv`, `pyproject.toml`, and project-based Python workflows.
- [uv: Running Scripts](https://docs.astral.sh/uv/guides/scripts/)  
  Explains how to run Python scripts with `uv`.
